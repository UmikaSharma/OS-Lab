# Operating Systems Lab

This repository contains practical exercises and implementations covering fundamental Operating System concepts using **Bash Shell Scripting, Linux commands, and C programming**.

## Topics Covered

- Basic Bash commands, I/O redirection, pipes, and file/directory operations.
- File searching, process management, and Vi/Nano editors.
- Linux commands: `date`, `who`, `sed`, `free`, `top`, `pmap`, and `time`.
- Shell scripting for file handling, text manipulation, and user/process information.
- String operations using Shell Scripts and C.
- Memory allocation and memory usage analysis.
- CPU-bound and I/O-bound process analysis.
- Process creation, child processes, and PID management.
- Process memory mapping and virtual memory address observation.

## Languages & Tools

- C
- Bash Shell Scripting
- Linux / Ubuntu
- GCC Compiler
